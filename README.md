## 🚀 Featured projects

### [BISUNI](https://github.com/Yamato6/BISUNI-v2): university management system
`Java 21` `JavaFX` `Next.js` `TypeScript` `PostgreSQL` `Flyway` `Drizzle`

A complete school management system with two apps over one PostgreSQL database:
- **Desktop app** (JavaFX) for staff and teachers: admissions, academic periods, groups, conflict-free
  timetables, grades and grade closing, attendance, announcements, and an audit log.
- **Web portal** (Next.js) for students and applicants: grades, transcript with credit progress, timetable,
  attendance, and PDF certificates.
- Business rules enforced **in the database** (constraints and triggers), bcrypt passwords, and an audit trail
  filled automatically by triggers.
- **200+ automated tests** against a real (embedded) PostgreSQL, including an end-to-end flow across both apps,
  plus GitHub Actions CI and a packaged Windows release (jpackage).

Rewrite of my original school project (MySQL, Swing, PHP).

### [AstroPlanner](https://github.com/Yamato6/AstroPlanner): astronomy observation planner
`C#` `.NET 8` `WPF` `MVVM` `xUnit`

A Windows app that answers *what can I see tonight, when, and under which sky*:
- Positions of the 110 Messier objects and the planets.
- Twilight and Moon phase, an hourly cloud forecast (Open-Meteo), and a sky chart.
- An observing plan and a logbook.
- Astronomy algorithms implemented from scratch.
- **Clean Architecture** with strict MVVM and **185 tests**, validated against Meeus' reference examples.
- CI, plus an installer and a portable build published on every release.

### [VNTools](https://github.com/Yamato6/VNTools): reverse-engineering toolkit for visual novel translation
`Python` `Reverse engineering` `Binary formats` `PyInstaller`

Tools to extract, edit and repack the assets of Japanese visual novels for fan translations:
- Support for **9 game engines** (FVP, CatSystem2, KiriKiri, SiglusEngine, BGI, NeXAS, AdvHD, Yeti and FS).
- Archives, compressed and encrypted formats, images, audio and script bytecode, figured out from the binaries.
- Script rebuilds **relocate every jump and pointer**, so translated lines can be longer than the original.
- Each tool has a GUI and a CLI, and is built into a standalone `.exe`. 14 releases so far.
